# Third-party assets

The following font files are distributed separately from the MIT-licensed converter code:

| File | Internal family | Embedding flag |
|---|---|---|
| `assets/fonts/PreTesto-Italic.ttf` | `PreTesto` | SIL Open Font License 1.1; installable embedding |
| `assets/fonts/XuanZongTi.otf` | `XuanZongTi` / `玄宗体` | SIL Open Font License 1.1; installable embedding |

`assets/fonts/OFL-1.1.txt` contains the license text. XuanZongTi is distributed from [kaonashi-tyc/Zi-XuanZongTi](https://github.com/kaonashi-tyc/Zi-XuanZongTi); the local file matches the official repository's SHA-256. PreTesto is derived from Unna by Omnibus Type and is distributed under OFL 1.1.

The `narrative` theme in this version is an independent implementation and does not include files or code from Esther Design System.
