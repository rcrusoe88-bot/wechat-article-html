# Third-party assets

The following font files are distributed separately from the MIT-licensed converter code:

| File | Internal family | Embedding flag |
|---|---|---|
| `assets/fonts/Caveat-Bold.ttf` | `Caveat` | SIL Open Font License 1.1; installable embedding |
| `assets/fonts/XuanZongTi.otf` | `XuanZongTi` / `玄宗体` | SIL Open Font License 1.1; installable embedding |

`assets/fonts/Caveat-OFL.txt` and `assets/fonts/XuanZongTi-OFL.txt` contain the corresponding license texts. Caveat is distributed from [googlefonts/caveat](https://github.com/googlefonts/caveat); the local `Caveat-Bold.ttf` matches the official repository's SHA-256 (`29E5CF4177D79AF56C256C24F687FD6A74C3D04C3C4660CCCA87B0A6D1FA3452`). XuanZongTi is distributed from [kaonashi-tyc/Zi-XuanZongTi](https://github.com/kaonashi-tyc/Zi-XuanZongTi); the local file matches the official repository's SHA-256.

The `narrative` theme in this version is an independent implementation and does not include files or code from Esther Design System.
